## v1.0.0 — 2026-09-21

- Initial release by Skill Foundry
- Systematic code simplification workflow: understand → identify → apply → verify
- Five Principles: Preserve Behavior, Follow Conventions, Prefer Clarity, Maintain Balance, Scope Changes
- Anti-rationalization table addressing common simplification excuses
- Language-specific patterns for TypeScript, Python, React, and Go
- Rule of 500 guideline for large-scale refactors
- 8 eval cases (5 positive triggers, 3 near-miss negatives)
- Progressive disclosure with references/ for deeper dives
