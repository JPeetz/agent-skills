## [1.0.0] — 2026-09-14

### Added

- Initial release of the spec-writer skill
- Full SKILL.md with YAML frontmatter, Overview, When to Use, How to Invoke, Output Format, Assumption Markers, Common Pitfalls, and Verification sections
- MIT License (2026 JPeetz)
- Evaluation suite with 5 test cases covering: happy-path feature spec generation, non-functional requirements inclusion, assumption marker correctness, edge-case coverage, and plan-vs-spec separation
- Base methodology: spec-driven development (SDD) with inline assumption flagging, binary acceptance criteria, and ordered task breakdown
