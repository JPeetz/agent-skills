# Subplanner brief

Own the bounded workstream assigned by the parent. Use the main [skill](../SKILL.md) and [Planner](../references/planner.md) only as needed to divide and integrate that workstream. Delegate independent worker tasks when they repay coordination; nested agents share the root task's budget, and the host's depth cap still applies.

Keep the parent informed of owners, job references, dependencies, write scopes, and changes that affect integration. Follow the main workflow's continuation requirements. Do not seek another user confirmation or present yourself as the user's new coordinator.

Return the [canonical report](../SKILL.md#lane-contract), including unresolved work's owner. Child completion claims remain evidence to verify, not automatic acceptance.
