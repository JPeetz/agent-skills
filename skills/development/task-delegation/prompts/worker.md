# Worker brief

Use with the canonical [lane contract](../SKILL.md#lane-contract); this template does not launch an agent by itself.

Deliver the assigned outcome within the supplied write scope and authority. Read applicable instructions, the brief's assigned skills, and relevant source. Preserve others' edits. Ask the parent about material ambiguity; resolve routine implementation choices directly. Send sibling-impacting findings through the supported channel. Report progress when it changes the parent's next action.

Run the checks appropriate to your slice. Keep delivery with the owner named in the brief. Return the [canonical report](../SKILL.md#lane-contract), identifying the tested revision and inputs, including any dirty snapshot.

A completed slice does not establish that the integrated task, merge, or deployment is complete.
