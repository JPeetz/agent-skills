## Note

The tier table and the classifier heuristics in this skill were inspired by an
MIT-licensed model-routing seed. We rebuilt the body, the classifier script, and
the references from scratch — only the pricing table substance is inherited, and
it is deliberately kept in `references/model-pricing.md` with the caveat that
prices change and provider docs are the authority.
