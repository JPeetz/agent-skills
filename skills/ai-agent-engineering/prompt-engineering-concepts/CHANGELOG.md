# Changelog — prompt-engineering-concepts

## v1.0.0 — 2026-11-17

- Initial release. The 20 core prompting techniques as a selection table
  (technique / when it earns its tokens / the exact move), a time-pressured
  selection path, an ordered procedure, eight named pitfalls, and an
  output-side verification checklist.
- `references/20-concepts-cheatsheet.md`: verbatim transcription of the source
  poster — Akhil Meesala, *20 Prompt Engineering Concepts: A Compact Cheatsheet
  with Ideas, Use Cases and Visualizations*.
- Deliberately scoped as the *choosing* layer. Production prompt anatomy, quality
  scoring, A/B discipline and per-platform delimiter conventions are not repeated
  here; judge calibration lives in `agentic-eval`, injection hardening in
  `prompt-injection-defense`.
