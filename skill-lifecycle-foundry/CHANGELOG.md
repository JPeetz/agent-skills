# Changelog

## [1.0.0] - 2026-08-24

- Initial release of the Skill Lifecycle Foundry meta-skill.
- Covers the full agent-skill lifecycle: mining session/archive history for
  repeated workflows, authoring new `SKILL.md` files, personalizing existing
  skills to local tools and phrasing, and generalizing private skills for
  public release with secret/path redaction.
- Ships a release checklist and a reference-based progressive-disclosure
  structure so skills stay lean and trigger well.
- Includes `evals/evals.json` with should-trigger and not-trigger cases and
  verifiable assertions.
